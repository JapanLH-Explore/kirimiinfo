# kirimiinfo

Public App Store support and privacy pages for **日本語の中へ (Nihongo no Naka
he)**.

- support.html — gameplay, purchase/restore help, and contact details
- privacy.html — local story data and RevenueCat purchase processing
- index.html — front page linking to both
- style.css — shared local stylesheet

GitHub Pages serves the files directly from main. There is no build step and no
third-party script, font, analytics, or embed on these pages.

The private game repository contains the canonical Markdown in
docs/app-store/privacy-policy.md and docs/app-store/support.md. Change both
repositories together so the public promises match the submitted binary.

The current app has no accounts, ads, IDFA access, or cross-app tracking. Story
names, progress, vocabulary, and settings stay on the device. Apple and
RevenueCat process an anonymous purchase identifier and transaction information
for the optional permanent Full Access purchase.

Do not publish the built games or RevenueCat secret keys here.
